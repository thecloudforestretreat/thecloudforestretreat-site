El ritmo del retreat

Donde el día se vuelve lento

Las mananas empiezan con café y la luz del bosque nublado. Las tardes se van entre senderos, jardines y rincónes tranquilos para leer. Las noches son para el fuego, la conversacion y una comida caliente cuando quieres algo simple. Todo esta pensado para sentirse fácil, sin apuro.
